# Project Scope

## 1. Purpose
The purpose of the University Library Management System is to provide a proposed computerized system for managing important university library activities.

## 2. In-Scope Features
- Book registration and management
- Book-copy records
- Member registration
- Student and faculty membership
- Book searching
- Availability checking
- Borrowing
- Returning
- Reservations
- Due-date management
- Overdue identification
- Overdue notifications
- Librarian management
- Basic reports

## 3. Out-of-Scope Features
- Complete production implementation
- Mobile application
- Online payment system
- Payment gateway
- Integration with external university systems
- Physical RFID hardware implementation
- Large-scale cloud deployment
- Commercial deployment

## 4. Objectives
1. Reduce manual record keeping.
2. Improve book tracking.
3. Improve borrowing and returning processes.
4. Make book searching easier.
5. Support book reservations.
6. Help librarians identify overdue books.
7. Improve organization and accuracy.
8. Provide a clear interface design.

## 5. Assumptions
- Library staff will provide required information.
- Users will have valid accounts.
- Librarians will maintain accurate records.
- The university provides basic computer facilities.
- Library policies are available for borrowing and overdue rules.

## 6. Constraints
- Two team members are available.
- The project has an academic deadline.
- Development time is limited.
- Complete implementation is not required.
- Requirements depend on information provided by the library.
