# Assignment 1 Submission Checklist

Use this checklist before submitting. Tick an item only after it is actually completed and visible in the repository.

- [ ] GitHub account created.
- [ ] Repository created with the exact name `university-library-management-system`.
- [ ] README includes the project description, objectives, team members, scope, assumptions, constraints, and folder structure.
- [ ] `requirements/` folder exists.
- [ ] `diagrams/` folder exists.
- [ ] `ui-prototype/` folder exists.
- [ ] `reports/` folder contains the project planning documents.
- [ ] Project schedule includes start dates, end dates, milestones, and deadline information.
- [ ] Gantt chart is included and its dates match the schedule table.
- [ ] WBS is included.
- [ ] Responsibility assignment matrix is included and reflects real contributions.
- [ ] Risk register includes likelihood, impact, and mitigation.
- [ ] Git is installed and the repository has been cloned to the computer.
- [ ] At least three meaningful commits appear in GitHub history.
- [ ] A GitHub Issue exists for every major Assignment 1 task.
- [ ] Issues have been assigned to the appropriate team member.
- [ ] Screenshots have been captured for the repository, commit history, and Issues.
- [ ] The repository URL is copied for submission.
- [ ] The real submission deadline and proposed schedule dates have been checked.
