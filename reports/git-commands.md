# Git Commands for Assignment 1

## Clone
```powershell
git clone https://github.com/muhammadahmadkhan299/university-library-management-system.git
cd university-library-management-system
```

## Check status
```powershell
git status
```

## Commit 1
```powershell
git add README.md reports/project-scope.md
git commit -m "docs: add project overview and scope"
```

## Commit 2
```powershell
git add reports/wbs.md reports/gantt-chart.md
git commit -m "docs: add project schedule and WBS"
```

## Commit 3
```powershell
git add reports/responsibility-matrix.md reports/risk-register.md
git commit -m "docs: add responsibilities and risk analysis"
```

## Push
```powershell
git push origin main
```

## View history
```powershell
git log --oneline
```
