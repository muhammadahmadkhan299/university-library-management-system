# University Library Management System (ULMS)

## Project Overview
The University Library Management System (ULMS) is a proposed system for managing the daily activities of a university library. The current process uses manual records or an outdated system. The proposed system will help library staff manage books, student and faculty memberships, book borrowing, returns, reservations, and overdue notifications in one organized place.

This repository contains the planning and software-engineering documents for the project. The team will analyse requirements, model the system, and prepare a clickable interface prototype. **The complete working software is not being implemented as part of this project.**

## Project Objectives
1. Maintain an organized catalogue of library books and copies.
2. Maintain student and faculty member records.
3. Record book borrowing and returns accurately.
4. Allow members to search for books and request reservations.
5. Identify overdue loans and prepare overdue notifications.
6. Reduce manual record-keeping and make library operations easier to track.
7. Prepare clear requirements, UML models, and a clickable user-interface prototype.

## Project Scope
### Included in the planned system
- Book and book-copy catalogue management.
- Student and faculty membership records.
- Searching and viewing book availability.
- Issuing books and recording due dates.
- Recording returned books.
- Reserving unavailable or available books according to library policy.
- Identifying overdue books and showing notification status.
- Separate access for students/members, librarians, and library administrators.
- Requirements documentation, UML diagrams, and a clickable prototype.

### Not included in this academic project
- Building and deploying a complete production system.
- Integrating with a real university student-information system.
- Processing online payments or fines.
- Purchasing or installing physical scanners, servers, or other hardware.
- Sending real SMS or email messages. Notification behaviour will be specified and demonstrated in the design/prototype only.

## Assumptions
- The university will provide or approve the library rules for loan periods, renewals, reservations, and overdue handling.
- Librarians are responsible for creating or updating book and member records.
- Each physical book copy can be identified separately from its book title.
- Students and faculty members will use university-approved membership details.
- The project team can obtain feedback from at least one person familiar with library work.
